# SpeedTest Website

A single-file HTML/CSS/JavaScript website adapted from the supplied Java speed test.

## Run it
1. Open `index.html` in a modern browser.
2. Press **Start Test** and allow the test to run for 8 seconds.

The browser needs internet access. The speed test uses Cloudflare's public download endpoint. Browser/network policies, ad blockers, and CORS availability can affect results. This measures download throughput only; it does not measure upload speed or ping.

## Publish it
Upload `index.html` to any static website host (for example GitHub Pages, Netlify, or Cloudflare Pages).
